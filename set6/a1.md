## Задача A1. Как построить минимальный остов?

### Task 1.

**Алгоритм 1: **  
Сортировка ребер по весу работает за `O(ElogE)` (это обычная сортировка массива)  
Для того чтобы получить список весь ребер, потребуется обойти граф - это `O(V + E)` (например, DFS). При условии, что структуру данных графа делаем в виде списка смежности (каждая вершина хранит информацию о соседях).  А если мы при добавлении ребер сразу сохраняем их в отдельный список, то это вообще O(1).  

Цикл foreach работает за `O(E)`.  
Удаление ребра `T - {e}` работает за O(v), если храним ребра в списках смежности.  

Далее, проверка графа на связность - это `O(V + E)` (используем DFS с подсчетом).  

В итоге получаем сложность AGL1: `O(ElogE) + O(V + E) + O(E) * O(V + E) = O(ElogE) + O(E*V + E^2) = O(E * V + E^2)`.  

**Но это можно оптимизировать, если для проверки связности использовать DSU!  **

Тогда на каждую проверку в цикле уйдет `O(E * alpha(V))`.  

Тогда общая сложность ALG1 получится: `O(ElogE) + O(V + E) + O(E) + O(E) * O(E * alpha(E)) = O(ElogE) + O(E^2 * alpha(E)) = O(E^2 * alpha(E))`  

В зависимости от количества вершин V в графе может быть более эффективным либо первый способ (с использованием DFS), либо второй способ (с использованием DSU).

```
def INSERT(key):
    ind = hash(key) % M
    cnt = 0 # счетчик для подсчета количества проходов 

    # если счетчик стал равен M, то завершаем цикл
    # если нашли ERASED, то завершаем цикл и выполняем вставку на это место
    while table[ind] is not None and table[ind] is not "ERASED" and cnt < M: 
        if table[ind] == key:
            return
        ind = (ind + 1) % M
        cnt += 1 # увеличиваем на каждой интерации

    if cnt < M:
        table[ind] = key
```
