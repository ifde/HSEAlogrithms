## Задача A1. Как построить минимальный остов?

### Task 1.

**Алгоритм 1:**    
Сортировка ребер по весу работает за `O(ElogE)` (это обычная сортировка массива)  
Для того чтобы получить список весь ребер, потребуется обойти граф - это `O(V + E)` (например, DFS). При условии, что структуру данных графа делаем в виде списка смежности (каждая вершина хранит информацию о соседях).  А если мы при добавлении ребер сразу сохраняем их в отдельный список, то это вообще O(1).  

Цикл foreach работает за `O(E)`.  
Удаление ребра `T - {e}` работает за O(v), если храним ребра в списках смежности.  

Далее, проверка графа на связность - это `O(V + E)` (используем DFS с подсчетом).  

В итоге получаем сложность AGL1: `O(ElogE) + O(V + E) + O(E) * (O(V) + O(V + E)) = O(ElogE) + O(E*V + E^2) = O(E * V + E^2)`.  

**Но это можно оптимизировать, если для проверки связности использовать DSU!**

Тогда на каждую проверку в цикле уйдет `O(E * alpha(V))`.  

Тогда общая сложность ALG1 получится: `O(ElogE) + O(V + E) + O(E) + O(E) * )O(V) + O(E * alpha(E))) = O(ElogE) + O(E^2 * alpha(E)) = O(E^2 * alpha(E))`  

В зависимости от количества вершин V в графе может быть более эффективным либо первый способ (с использованием DFS), либо второй способ (с использованием DSU).  

Ниже приведен пример реализации с помощью DFS:  

```
bool Graph::CheckConnection() {
  unordered_set<int> visited;
  DFS(adj.front().front(), visited);
  return visited.size() == V;
}

void Graph::removeEdge(int a, int b) {
  auto pos_a = find(adj[a].begin(), adj[a].end(), b);
  adj[a].erase(pos_a);
  auto pos_b = find(adj[b].begin(), adj[b].end(), a);
  adj[b].erase(pos_b);

  int weight;
  for (auto& edge : E) {
    if (edge.second.first == a && edge.second.second == b) {
      weight = edge.first;
      break;
    }
  }
  pair<int, pair<int, int>> pair = {weight, {a, b}};
  auto pos_c = find(E.begin(), E.end(), pair);
  E.erase(pos_c);
}

// Функция AGL1
vector<pair<int, pair<int, int>>> AGL1(Graph& graph) {
  vector<pair<int, pair<int, int>>> E = graph.E; // Получаем список рёбер
  sort(E.rbegin(), E.rend()); // сортировка по невозрастанию весов за O(ElogE)

  auto T = E;

  Graph new_graph(graph.V); // создаем новый граф, чтобы не удалять ребра из исходного
  new_graph.adj = graph.adj;
  new_graph.E = T;

  // Идем по всем ребрам за O(E)
  for (size_t e = 0; e < E.size(); e++) {
    int u = T[e].second.first;
    int v = T[e].second.second;

    new_graph.removeEdge(u, v); // удаляем ребро за O(v)

    // Проверка связности после удаления ребра {e} из T за O(V + E)
    if (new_graph.CheckConnection()) {
      T[e] = {-1, {-1, -1}}; // Если связан, то удаляем ребро из T
    } else {
      new_graph.addEdge(u, v, T[e].first); // иначе восстанавливаем ребро
    }
  }

  return T;
}
```
